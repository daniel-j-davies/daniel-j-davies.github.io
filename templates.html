Page Templates

Copy-and-paste blocks for updating the site. Each shows a live preview and the exact HTML. Click Copy HTML, paste it into the right page, then replace the ALL-CAPS placeholders. This page is not linked from the menu and is hidden from search engines.

How things are organised

  • Look and feel: assets/style.css (one file for every page).
  • Menu and footer: assets/site.js. Edit the PAGES list to add a page; the footer year updates itself.
  • Homepage updates: keep exactly five items, newest first. Paste the new one on top and delete the oldest.
  • New page: copy an existing page, change the <title>, description, canonical/og URLs and content, add it to PAGES in site.js and to sitemap.xml.
  • Publications: newest first inside each section.
