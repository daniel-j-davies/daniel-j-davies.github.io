# danieldavies.co

Personal academic website of Daniel Davies, served by GitHub Pages at <https://danieldavies.co>.

Plain HTML — no build step.

| What | Where |
| --- | --- |
| Pages | `*.html` in the repo root |
| Styles (shared) | `assets/style.css` |
| Menu, footer, mobile nav (shared) | `assets/site.js` (edit the `PAGES` list to change the menu) |
| Copy-paste blocks for updates, publications, courses | `templates.html` (open it in a browser) |
| Interactive projects | `berwick/`, `expulsion-atlas/`, `merchant-london/` |

Homepage "Latest Updates" holds exactly five items, newest first.
